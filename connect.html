Connecter un compte TikTok

1. Dans TikTok (navigateur ou appli), connecte-toi au compte à relier.
2. Colle la Client key de l'appli (developers.tiktok.com › ton appli), puis clique « Autoriser ».
3. Après « Autoriser » sur TikTok, la page de retour affiche un code à coller dans GitHub › Actions › Réglages › tiktok (avec le bon compte).
